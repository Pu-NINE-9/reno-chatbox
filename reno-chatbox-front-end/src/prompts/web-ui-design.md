生成一整套风格统一的AI对话平台UI，支持两种主题模式：
- 白天模式：白色+浅灰背景，搭配清新的绿色渐变作为主色调
- 夜间模式：深黑/深灰背景，搭配温柔的粉色渐变作为主色调
所有页面在两种模式下都保持设计语言和交互逻辑一致，配色自动切换。

1. 【主对话界面】
- 左侧边栏：顶部放置logo和平台名称，支持新建对话按钮；中间为可滚动的历史对话列表，hover高亮；底部为用户头像、设置入口。白天模式下为白色背景，黑色文字；夜间模式下为深灰背景，浅白文字。
- 右侧主区域：顶部显示当前对话标题；中间为对话消息区，用户消息居右、使用主题主色调背景，AI回复居左、使用中性色背景，支持loading状态提示；底部固定输入框，带发送按钮，支持多行输入扩展。
- 整体响应式设计，适配桌面端，交互元素用主题主色高亮，风格简洁清爽。

2. 【Token使用情况页面】
- 顶部导航与主界面保持一致。
- 主区域包含：token使用进度条、已用/剩余token数值统计、按时间/模型分类的使用趋势图表、历史使用记录表格。
- 采用卡片式布局，数据可视化清晰，配色随主题切换：白天模式用绿色渐变，夜间模式用粉色渐变。

3. 【404/500错误页面】
- 简约居中布局，显示错误代码（404 Not Found / 500 Server Error）、友好提示文案、返回首页按钮。
- 配色随主题切换：白天模式为白色背景+绿色按钮，夜间模式为深色背景+粉色按钮，风格简约统一。
